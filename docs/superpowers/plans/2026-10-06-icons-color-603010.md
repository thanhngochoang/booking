# Material Symbols Rounded and the 60‑30‑10 palette — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Battery/performance (2026-10-02, user):** no battery, idle or performance steps. **Rules emulator:** not touched by this plan.

> **Detail level (user, 2026-10-02):** exact interfaces, tests listed by name with expected behaviour, sample code only for the parts easy to get wrong.

**Goal:** One icon family (Material Symbols Rounded) in the mock, the component gallery and the app, and a disciplined 60‑30‑10 colour split: 60 % ink background and surfaces, 30 % neutral glass, secondary text and lines, 10 % violet accent reserved for the primary CTA, the active tab and selected states.

**Decision source:** the user, 2026-10-06 (`/ui-ux-pro-max`: "use the material font icon", "core color pattern 60 - 30 - 10 rules"; chosen options: Rounded, "Trung tính + tím", "Mock + tokens + app").

**Architecture:** Colours change only in `design-system/tokens.json` (→ `dart run tool/gen_tokens.dart` → `tokens.g.dart`) and the mock's CSS variables; widgets keep reading `AppColors`/`CtaSurface`. Icons go through one core catalogue `AppIcons` (`lib/core/theme/app_icons.dart`, exported by `core.dart`) built on the `material_symbols_icons` package (Rounded set, weight 400, optical size 24; filled variant for selected states). Features never reference `Icons.*` or `Symbols.*` directly (enforced by a test that scans `lib/features/**`).

**Tech Stack:** Flutter, `material_symbols_icons` (pub.dev), Google Fonts "Material Symbols Rounded" in the mock (`<link>` from fonts.googleapis.com, allowed for the published artifact).

## Global Constraints

- **60 % (dominant):** dark `bg #0B0B10`, `surface #17151F`; light `bg #F4F1EC`, `surface #FFFFFF`. Screens, sheets, cards sit on these.
- **30 % (secondary):** neutral glass (`glass`, `field`, `glass-hi`), secondary/tertiary text (`ink-2`, `ink-3`), lines. No hue.
- **10 % (accent):** violet only — dark `#B08AFF` (text/icon accent) and the CTA fill; light `#8338F5`. Used for: the one primary CTA per screen (`AppButton.primary` / `CtaSurface`), the active bottom-tab icon + label, selected chips/segments/option tiles, links, progress fills. Not used for: section titles, decorative borders, card backgrounds, non-selected icons.
- **CTA fill:** dark becomes a violet monochrome gradient `#8A3FFC → #6E2FD6` (replaces blue→violet→magenta); light keeps `#8338F5 → #702BDB`. The user's blurred-avatar CTA variant stays.
- **Cyan** `#14E0F5` only for the focus ring. **Spectrum colours** (cyan/violet/pink/orange/yellow) only inside `SignatureLoader`/`DotRingLoader` (brand loader), nowhere else.
- **Exempt (semantic, not part of the split):** status colours ok/warn/bad/pending/closed, gold for the NAG/Studio marks and award chips, photo content.
- **Icons:** Material Symbols Rounded, outline (FILL 0) by default, FILL 1 for selected/active (active tab, saved/liked, selected option); sizes 20 / 24 (default) / 28 as tokens `AppIconSize.sm/md/lg`; brand logos (Zalo, WhatsApp) and the app logo stay custom SVG (Material has no brand glyphs); `ProviderMark` seal/ticks stay custom painters.
- Contrast: accent text on dark surfaces ≥ 4.5:1 (`#B08AFF` on `#17151F` ≈ 6.9:1 ✓); CTA label white on `#6E2FD6` ≥ 4.5:1 ✓.
- Usual rules: tokens via `AppColors`/`AppSpace`/`AppRadius`, strings in arb, `package:photobooking/...` imports, features import `core/core.dart`, commit trailer `Co-Authored-By: TonyH <thanhngochoangbk@gmail.com>`.

## Decisions

1. **Icon package.** `material_symbols_icons` (`Symbols.*` with `fill`/`weight` via `Icon(…, fill: 1)`). If pub cannot be reached from the sandbox, the controller adds the dependency outside the sandbox (`flutter pub add material_symbols_icons`) before Task 3; nothing else changes.
2. **Mapping table.** `AppIcons` names the meaning, not the glyph (`AppIcons.home`, `.explore`, `.search`, `.add`, `.calendar`, `.profile`, `.chat`, `.favorite`, `.save`, `.share`, `.back`, `.place`, `.check`, `.notifications`, `.camera`, `.more`, `.settings`, `.darkMode`, `.mail`, `.lock`, `.forward`, `.phone`, `.payment`, `.swap`, `.star`, `.instant`, `.ticket`, `.award`, `.work`, `.close`, `.undo`, `.info`, `.dragHandle`, `.chevron`, `.album`, `.list`, `.image`, …) — one entry per mock symbol plus every distinct `Icons.*` now in `lib/` (98 today). The table lives in the plan's Task 3 and in `shared-components.md` → "Icons".
3. **Mock.** Replace the 41 `<symbol>` sprites and 195 `<use href="#i-…">` with `<span class="ms">name</span>` (CSS: `font-family:'Material Symbols Rounded'; font-variation-settings:'FILL' 0,'wght' 400,'opsz' 24`; `.ms.on` sets FILL 1). Keep `i-whatsapp`, `i-zalo`, `i-logo`, `i-seal` as SVG.
4. **Gallery.** `scripts/tools/build_ui_components.py` regenerates `docs/design/ui-components.html` from the mock CSS; it gains an "Icons" section listing the mapping table, and the "Màu" section shows the 60/30/10 swatches.

## Review Focus

1. No `Icons.` / `Symbols.` in `lib/features/**` (test "features use AppIcons only").
2. Only one accent-filled element per screen outside lists (primary CTA); the active tab uses accent; nothing else decorative uses accent (spot-check S01.01, S02.01, S03.01, S05.01, S09.01 goldens-free widget tests that assert colours of key elements).
3. Dark CTA gradient no longer contains blue/magenta (`CtaSurface` test).
4. Focus ring still cyan; loaders still spectrum.
5. Mock and app agree on every icon (mapping table is the single list).
