## Decisions

1. **S01.03 keeps the sign-up link; the mock is stale.** Without "Chưa có tài khoản? Đăng ký" there is no way to reach S01.04 (the audit calls it a deviation, but the spec `account.md` S01.03 lists `noAccountPrompt` + `registerLink`, and S01.04's own frame has the mirror row "Đã có tài khoản? Đăng nhập"). The mock frame gets the row; the app does not change.
2. **S01.03 field icons and the show/hide eye stay.** The spec lists `showPassword`/`hidePassword`; the mock frame is a static picture. The caption of `#S01.03` is updated to name them, so the next audit does not flag them again.
3. **S01.04 drops the AppBar (mock wins).** Back navigation stays available through the system back gesture/button and the "Đăng nhập" link under the card. The link must also work when `/register` was opened directly (deep link, empty stack): `canPop` → `pop`, else `go('/login')`.
4. **S01.04 "Đăng ký" has no icon** (mock `btn pri` "Đăng ký" has none; S01.03 "Đăng nhập" keeps its arrow, as in its frame).
5. **S01.05 icon tile:** the mock draws each role's icon in a 36 dp circle (`.ic`): selected → `primarySubtle` fill with a `primary` icon; unselected → the field colour (`colorScheme.secondary`) with the normal foreground icon. Card border/fill rules stay as they are.
6. **S01.01 Splash and S01.02 Lỗi phiên are not touched**, so no mock frame is added for them (caller ruling: add frames only when the plan touches the screen). They stay "Chưa có mock" and are listed under Deferred.
